# Rate desk

[Live demo](https://spotter-rate-desk.vercel.app)

A small working demo of the assessment model. Plain HTML, CSS and JavaScript
provide the interface. A Python endpoint serves the actual fitted CatBoost model
using its standalone export, with no runtime packages to install.

The interface supports the 64 training cities, three equipment types and pickup
dates in November-December 2025. It includes a fixed-load December chart and a
short explanation of the chronological validation. No input history is stored by
the application. Raw assessment datasets are not included in the deployment.

## Preview

From the repository root:

```bash
python demo/serve.py
```

Open `http://127.0.0.1:8765`. The checked-in export works with the Python standard
library. It does not require the training environment for serving.

## Refresh the exported model

After training, use the assessment environment:

```bash
python export_demo.py
python -m unittest discover -s tests -v
```

`model/exported.py` is generated by CatBoost and excluded from formatting. Its
numeric and categorical feature order is recorded in `model/metadata.json`.
The export was checked against the native model on 128 supported-city validation
loads and all 31 December inputs. The public tests also check numeric split
boundaries. Native float32 inputs and full-precision thresholds are preserved.

## Vercel

Deploy `demo/` as the project root, using the Other framework preset. Static
assets are in `public/`; `api/predict.py` is the prediction endpoint. The Python
version and function configuration are included.

```bash
vercel --cwd demo --prod
```

The original training workflow and submission artifacts remain in the repository
root. This demo does not change the selected model or its prediction files.
