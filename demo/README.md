# Rate desk

[Live demo](https://spotter-rate-desk.vercel.app)

HTML, CSS and JavaScript interface with a Python prediction endpoint. The
endpoint runs the fitted additive model and CatBoost correction using the Python
standard library. Raw assessment data is excluded from the deployment.

The demo supports 64 training cities, three equipment types and pickup dates in
November–December 2025. It includes the December chart and validation results.

## Run locally

From the repository root:

```bash
python demo/serve.py
```

Open `http://127.0.0.1:8765`. Training packages are not needed to serve the
included model export.

## Update the model

After training, use the training environment:

```bash
python export_demo.py
python -m unittest discover -s tests -v
```

`model/exported.py` is generated by CatBoost. `model/metadata.json` stores feature
order, numeric thresholds and additive coefficients. The export is checked
against native predictions on supported-city loads, all December rows and
numeric split boundaries.

## Deploy

Use `demo/` as the Vercel project root with the Other framework preset. Static
files are in `public/`, and `api/predict.py` handles predictions.

```bash
vercel link --cwd demo --project spotter-rate-desk --yes
vercel --cwd demo --prod --archive=tgz
```

`.vercelignore` excludes local caches and environment files.
